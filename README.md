# Equà Studio

Marketing website for **Equà Studio** — a premium aesthetics & beauty studio founded by Sahrish, located in Bahria Town, Lahore. The site presents the studio's full service menu, location, and story, with every enquiry routed straight to WhatsApp for a free consultation.

---

## Tech Stack

- **[TanStack Start](https://tanstack.com/start)** — full-stack React framework (file-based routing via TanStack Router)
- **React 19** + **TypeScript**
- **Vite** — dev server & build tool
- **Tailwind CSS v4**
- **shadcn/ui** (Radix UI primitives) — accordion, dialog, form, tabs, etc.
- **React Hook Form** + **Zod** — form handling & validation
- **Cloudflare Workers** — deployment target (via `wrangler`)

This project was originally scaffolded with [Lovable](https://lovable.dev).

## Getting Started

### Prerequisites

- Node.js (LTS recommended) — install via [nvm](https://github.com/nvm-sh/nvm)
- npm (or bun — a `bun.lock` is present if you prefer [Bun](https://bun.sh))

### Setup

```sh
git clone <this-repository-url>
cd equa_project
npm install
npm run dev
```

The dev server runs at `http://localhost:8080` (or the port Vite reports in the terminal).

### Available Scripts

| Command              | Description                          |
| --------------------- | ------------------------------------- |
| `npm run dev`          | Start the local dev server with HMR    |
| `npm run build`        | Production build                       |
| `npm run build:dev`    | Development-mode build                 |
| `npm run preview`      | Preview the production build locally   |
| `npm run lint`         | Run ESLint                              |
| `npm run format`       | Format the codebase with Prettier       |

## Project Structure

```
src/
├── assets/            # Studio & treatment photography
├── components/
│   ├── Sections.tsx    # Shared page sections (e.g. BookingCta)
│   ├── SiteHeader.tsx
│   ├── SiteFooter.tsx
│   └── ui/             # shadcn/ui components
├── hooks/
├── lib/
│   └── studio.ts        # Central studio config: name, contact, address, WhatsApp, hours
├── routes/              # File-based routes (TanStack Router)
│   ├── __root.tsx
│   ├── index.tsx         # Home
│   ├── about.tsx
│   ├── services.tsx      # Full treatment menu, grouped by "collective"
│   ├── appointment.tsx   # Booking flow
│   └── location.tsx
├── routeTree.gen.ts     # Auto-generated by TanStack Router — do not edit by hand
├── router.tsx
├── server.ts
├── start.ts
└── styles.css
```

### Key Conventions

- **Studio-wide details** (phone, WhatsApp number, address, socials, hours) live in one place: `src/lib/studio.ts`. Update contact info there rather than hardcoding it in individual routes.
- **Services page** (`src/routes/services.tsx`) organizes treatments into **collectives** (Hand & Foot, Semi-Permanent Makeup, Brow & Lash, Hair & Scalp, Bridal/Artistry, Facial, Grooming, Wellness). Each collective has a thumbnail image and expands into an accordion listing individual treatments. There is no pricing shown — every row has a **"Book a Free Consultation"** button that opens WhatsApp with a pre-filled message naming that specific service.
- Routes are file-based: adding a file under `src/routes/` automatically registers a route (TanStack Router's Vite plugin regenerates `routeTree.gen.ts`).

## Deployment

The project deploys to **Cloudflare Workers**, configured via `wrangler.jsonc`:

```sh
npm run build
npx wrangler deploy
```

This builds the TanStack Start app to `.output/` and deploys the server bundle and static assets as defined in `wrangler.jsonc`.

## Notes for Contributors

- Match the existing visual language when adding new UI — soft shadows (`shadow-[var(--shadow-soft)]`), muted mauve/cream palette, and `rounded-lg`/bordered image treatments (see the services accordion thumbnails and the testimonial card on the homepage) rather than plain circular avatars.
- All outbound enquiry actions (booking, consultations) should route through WhatsApp using `STUDIO.whatsapp` from `src/lib/studio.ts`, with a clear, pre-filled message — this keeps the contact flow consistent across the site.
